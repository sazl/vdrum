# VDrum

A Rust port of the sound engine of the Erica Synths LXR-02 drum machine firmware, as a standalone
application and CLAP / VST3 / AU plugin. Unofficial; not affiliated with or endorsed by Erica Synths.
Based on the GPL-3.0 LXR firmware source (https://github.com/erica-synths/lxr-desktop-app); this
project is licensed GPL-3.0-only.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
